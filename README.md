# 快乐票1 —— 真实数据版

> 对应产品文档：《快乐票.md》（在桌面）。本版本用爬虫抓取【中国竞彩网（官方）】的真实赔率数据，并在网站中展示。

支持 5 种玩法：**胜平负 / 让球胜平负 / 比分 / 总进球 / 半全场**。

## 和演示版（kuailepiao）的区别

| | 演示版 kuailepiao | 真实数据版 kuailepiao1 |
|---|---|---|
| 数据 | 手工编的示例 | 官方竞彩网真实抓取 |
| 场次 | 7 场 | 全部在售场次（抓取时约 50 场） |
| 走势图 | 编的曲线 | 真实赔率变动快照 |

## 怎么打开看

1. 打开文件夹 `kuailepiao1`，双击 `index.html`
2. 点任意比赛卡片，进入详情页看**赔率走势图**和**信号提示**
3. 详情页顶部可切换 5 种玩法：胜平负、让球胜平负是折线走势图；比分、总进球、半全场选项较多，用表格展示（含初盘→当前的涨跌）

## 怎么更新数据（重要）

赔率会变，需要运行爬虫重新抓取：

1. 双击 `crawler.py`（需要电脑装了 Python；本机已装 3.13）
   - 或在命令行运行：`python crawler.py`
2. 运行后会重新生成 `js/live-data.js`，**刷新网页**即可看到最新数据

> 建议每 5~10 分钟运行一次来积累走势数据。正式版（V2）会把这套爬虫放到云服务器上定时自动运行，用户就能随时看到实时数据。

## 数据来源与合规

- 数据来源：中国竞彩网官方接口（webapi.sporttery.cn）
- 只做数据展示与统计，不提供销售 / 代购服务
- 请控制抓取频率，遵守数据方服务条款；正式上线前建议咨询法律人士

## 文件说明

| 文件 | 作用 |
|---|---|
| crawler.py | 爬虫：官方接口 → js/live-data.js（含每场 5 种玩法的历史走势快照，供走势图/表格使用） |
| index.html / match.html | 首页 / 详情页 |
| js/live-data.js | 爬虫生成的真实数据（勿手改） |
| js/signals.js | 信号分析（降赔/低赔/升赔，诚实标注"数据积累中"） |
| js/home.js / match.js | 页面逻辑 |
| css/style.css | 样式（复用演示版） |
